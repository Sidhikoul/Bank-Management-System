Bank Management System

A full-stack Bank Management System developed as a Database Management System (DBMS) mini project.

Features

- User Registration
- Secure Login (bcrypt password hashing)
- Account Creation
- Deposit Money
- Withdraw Money
- Fund Transfer
- Transaction History
- MongoDB Database Integration
- REST API using Express.js

Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- HTML
- CSS
- JavaScript
- bcryptjs

Project Structure

Installation

```bash
git clone https://github.com/YOUR_USERNAME/Bank-Database-DBMS.git
cd Bank-Database-DBMS
npm install
npm start
```

Bank Management System

A Bank Management System developed as a Database Management System (DBMS) mini project. This application simulates basic banking operations such as account creation, secure login, deposits, withdrawals, fund transfers, and transaction history management using a relational database.

------------------------------------------------------------

Project Overview

The project demonstrates the implementation of a banking system using SQL concepts along with a simple web interface. It focuses on efficient data storage, secure user authentication, and transaction management while maintaining data integrity.

------------------------------------------------------------

Features

- User Registration
- Secure User Login
- Create Bank Account
- Deposit Money
- Withdraw Money
- Fund Transfer Between Accounts
- View Account Details
- Transaction History
- Input Validation
- SQL Database Integration
